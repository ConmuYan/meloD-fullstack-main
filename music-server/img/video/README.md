# 视频资源目录

## 目录说明
此目录用于存放网站的视频资源文件。

## 主页背景视频

### 文件位置
- 文件名：`hero-background.mp4`
- 完整路径：`/music-server/img/video/hero-background.mp4`
- 访问URL：`http://localhost:8888/img/video/hero-background.mp4`

### 视频要求
1. **格式**：MP4格式（H.264编码）
2. **分辨率**：建议1920x1080或更高
3. **时长**：建议10-30秒（会自动循环播放）
4. **文件大小**：建议控制在10MB以内，确保加载速度
5. **内容**：适合作为背景的抽象或音乐相关内容
6. **音频**：视频会静音播放，可以包含音频但不会播放

### 技术特性
- 自动播放（autoplay）
- 静音播放（muted）
- 循环播放（loop）
- 移动端兼容（playsinline）
- 渐入效果（opacity动画）

### 备用方案
如果视频加载失败，页面会自动回退到原有的渐变背景，确保用户体验不受影响。

### 使用说明
1. 将符合要求的MP4视频文件重命名为 `hero-background.mp4`
2. 放置在此目录下
3. 重启服务器或刷新页面即可看到效果

### 注意事项
- 确保视频内容适合作为网站背景
- 避免过于复杂或分散注意力的内容
- 考虑不同设备的性能和网络条件
- 定期检查视频文件的可访问性
